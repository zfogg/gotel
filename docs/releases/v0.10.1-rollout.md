# v0.10.1 application span-prefix rollout

Verified on 2026-10-24. Prefixes remain enabled by default for gotel users.
The five consumers below explicitly disable them. Service names, resource
attributes, instrumentation scopes, metrics, trace IDs and parent IDs retain
their existing meanings. Historical stored spans are not rewritten.
